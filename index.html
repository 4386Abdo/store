دليل الربط مع Supabase

النظام يعمل مباشرة وتُحفظ بياناته على جهازك، ويمكن ربطه بقاعدة بيانات Supabase لتظهر بياناتك على كل أجهزتك.

دليل ربط Supabase واختبار الأمان

1. إنشاء المشروع

أنشئ مشروعا جديدا على supabase.com.

2. تشغيل كود SQL

افتح SQL Editor في Supabase والصق محتوى ملف sql/schema.sql واضغط Run (الملف يتضمن أعمدة حالة المنتج جيد/متوسط/سيئ).

3. إنشاء حساب المسؤول

من Authentication -> Users أنشئ المستخدم editor@studio-inventory.local مع كلمة مرور 6 أرقام (PIN).

4. إدخال المفاتيح

انسخ Project URL و anon key وضعهما في صفحة الإعدادات.

اختبار الأمان:

في صفحة owner.html افتح Console واكتب أمر التعديل:
await supabase.from('items').update({ quantity: 999 }).eq('sku', 'PRN-1015');
سترفض قاعدة البيانات العملية فورا برسالة خطأ في RLS لأن التعديل مقصور على دور المسؤول.
