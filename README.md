# إدارة مخزون — HTML + CSS + JavaScript فقط

بدون React أو Vite أو أي أدوات بناء. افتح المجلد على أي استضافة ثابتة وسيعمل.

## الصفحات
- `index.html` الرئيسية وزر تثبيت التطبيق
- `editor.html` واجهة المسؤول (الرمز الافتراضي 123456)
- `owner.html` واجهة العرض فقط (الرمز الافتراضي 654321، يُفعَّل من الإعدادات)

## المميزات
الأصناف والتصنيفات والموردين، تعديل سريع +/-، حركات مسجلة مع تراجع، جرد فعلي، قوالب شغل، قائمة نواقص مع إرسال واتساب، ملصق QR حقيقي قابل للمسح وللطباعة، ماسح باركود بالكاميرا، تصدير CSV ونسخ احتياطي JSON، قفل بعد 5 محاولات خاطئة، خروج تلقائي بعد 15 دقيقة، يعمل بدون إنترنت.

**الجديد: حالة المنتج (جيد / متوسط / سيئ)** مع ملاحظة، تعديل سريع من الجدول، فلتر، عداد في الأعلى، وتظهر في واجهة العرض والنواقص وCSV.

## تشغيله على الموبايل كتطبيق
1. ارفع المجلد كله على استضافة مجانية بـ HTTPS (Netlify Drop أو Cloudflare Pages أو GitHub Pages).
2. افتح الرابط من الموبايل: أندرويد/كروم زر «تثبيت التطبيق» أو القائمة ثم «تثبيت التطبيق»، آيفون/سفاري زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».

## حفظ البيانات والدخول بالرمز من أي مكان
- **بدون إعداد:** البيانات تُحفظ على نفس الجهاز (localStorage). لا تمسح بيانات المتصفح، وصدّر نسخة JSON من الإعدادات بشكل دوري.
- **لحفظها في السحابة ورؤيتها من كل أجهزتك:** اربط Supabase (مجاني)
  1. أنشئ مشروعا على supabase.com
  2. SQL Editor: الصق `sql/schema.sql` ثم Run
  3. Authentication ثم Users: أنشئ `editor@studio-inventory.local` وكلمة مرورها رمزك (6 أرقام فأكثر)، وكذلك `viewer@studio-inventory.local` لرمز العرض
  4. من الإعدادات في التطبيق ضع Project URL وanon key واحفظ
  بعدها أي جهاز تفتح عليه الرابط وتدخل بالرمز تجد نفس البيانات.

## ملاحظات أمان
في الوضع المحلي الرمز يحمي الواجهة فقط ولا يشفّر البيانات على الجهاز. للحماية الحقيقية استخدم Supabase.
